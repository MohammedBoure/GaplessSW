# Sandbox Environment Directory (`sandbox_env`)

This directory serves as the restricted working directory (`cwd`) for all `agy --sandbox` child processes spawned by [`src/services/agyManager.js`](../src/services/agyManager.js).

## Security Guardrails Inside `sandbox_env`
- `GEMINI.md`: Automatically generated by [`src/security/sandbox.js`](../src/security/sandbox.js) with strict instructions forbidding command execution or host file modifications.
- `.agents/hooks.json` & `.agents/scripts/tool-gate.js`: Lifecycle `PreToolUse` hook that hard-denies `run_command`, `write_file`, `edit_file`, and all mutating tools while allowing read-only inspection of client images inside `uploads/`.
